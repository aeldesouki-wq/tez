# كتب الأدب بصيغة Markdown (مرتبةً بوفاة المصنِّف، الأقدم أولاً)

المصدر: المكتبة الشاملة (shamela.ws)، جُلبت كل صفحات كل كتاب آلياً بلا اختصار، وحُوِّلت إلى Markdown. لا تعديل على النص إلا حذف أزرار الواجهة والروابط.

بنية كل ملف: ترويسة YAML (العنوان، المؤلف، الوفاة، رقم الشاملة، عدد الصفحات)، ثم `## عنوان القسم` عند تغيّره، ثم قبل كل صفحة سطر `<!-- جـ ص | pageId -->` وسطر `**[ج ص]**` برقم الجزء والصفحة المطبوعة، ثم المتن، ثم الحواشي في اقتباس `> **الحواشي:**`.

## تنبيهات
- ما ليس في الشاملة لم يدخل (تعليم المتعلم للزرنوجي، منية المريد، آداب المتعلمين للطوسي، الكافي… انظر `المهمة-١٩`).
- كشف الظنون استُبعد لأنه فهرس كتب لا كتاب آداب.
- تاريخ الوفاة المثبت هنا للترتيب فقط، وتقريبي في الراغب.
- عدد الصفحات المجلوبة قد يخالف «عدد الصفحات» المعلن في صفحة الكتاب (معرّفات الشاملة ليست أرقام الصفحات المطبوعة)؛ لم تُرصد ثغرات في تسلسل المعرّفات.
